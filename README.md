# Joshua Baysore

I build practical systems. I decide the problem and the limits; AI coding agents build inside them.

Portfolio: https://joshbaysore.com

## Public source

- **[Agentic Harness](https://github.com/jbaysore/agenticharness)** — A workspace for coding agents. Each chat works on its own copy of the project, and a change lands only after the check passes.
- **[DrivePartitionTool](https://github.com/jbaysore/drivepartitiontool)** — A file browser with whole-drive search and disk tools. The part that can change a disk runs once per approved plan and is tested only on virtual disks.
- **[Cutroom](https://github.com/jbaysore/cutroom)** — A keyboard-first video editor where the narration is the spine. AI drafts text, and the person makes every edit.

Most of my other projects are private; their stories are on the portfolio.
